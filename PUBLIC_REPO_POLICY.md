# Public repository data policy

This repository is public. It must contain benchmark code and synthetic benchmark data only.

## Forbidden content

Never commit any personal or deployment-specific information, including:

- real names, personal usernames, email addresses, phone numbers, home/work locations, account identifiers
- passwords, access tokens, API keys, private keys, certificates, cookies, session identifiers
- database connection strings, database/schema/table names copied from a real system, database usernames, database hostnames
- server hostnames, public or private IP addresses, SSH configuration, internal domains, cloud resource IDs
- production logs, production rows, screenshots, dumps, state files, environment files, local configuration
- copied source that still contains organization-specific identifiers or comments

Performance kernels inspired by real systems must be rewritten as generic algorithms with synthetic identifiers and deterministic generated input.

## Allowed content

- generic benchmark algorithms
- deterministic synthetic inputs generated by the benchmark itself
- public documentation links and public upstream project/release URLs
- compiler/runtime version numbers
- benchmark results containing only public runner/toolchain/CPU metadata

## Review rule

Every change must pass `scripts/check_public_repo.py`. A passing scan is a minimum gate, not permission to publish information that is known to be personal or deployment-specific.
